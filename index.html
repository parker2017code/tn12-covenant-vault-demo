Accepted transaction indexer

App state derived from TN12 reads.

This checkpoint turns accepted proof spends and payload events into app-state records. Vaults, assurance campaigns, escrow, and payload receipts should pass through replay before the UI updates app state.

DeFi replay checks

Accepted TN12 receipts, transfers, and reducer checks.

Session users and pool wallets execute funding, deposits, and payouts on TN12. Pricing, oracle inputs, liquidation, production custody, and user-wallet signing still need their own rules.

Open wallet handoff and draft review

Wallet handoff

Review before any testnet broadcast.

Check inputs, outputs, fees, payload state, and submit commands before signing. The user-wallet path is: review a request, sign outside the repo, return signed bytes, then submit and replay after acceptance.

Show signed draft registry 
npm run submit:registry
npm run wallet:review
npm run wallet:connector
