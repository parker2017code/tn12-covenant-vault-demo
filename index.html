TN12 configured. Proof transactions accepted.

Build vault and assurance rules against testnet, then verify them.

A vault is a covenant-shaped app: funds can only leave through known paths, such as a delay, a daily limit, or recovery. Assurance contracts are the group-funding cousin: release funds only if a target is met, otherwise refund. This repo now has real TN12 funding, spend, submit, and verification scripts; the browser is the policy/control surface.

            Can claim
            TN12 vault and assurance proof transactions, covenant-shaped UX, signed/broadcast scripts, and explorer-verifiable testnet outputs.
            
        
            Cannot claim
            Mainnet covenant activation, live native DeFi, full vProgs, wallet safety, arbitrary header data, or production wallet integration.
