Three strongest demos

Best fit for Kaspa's edge.

1 Blitz Mux Arena

A hub covenant routes state to worker A or B. Workers return state to the hub, bad selectors fail, and timeout handles a stalled branch.

  • Mux / worker contract family.
  • Template routing.
  • Accepted TN12 genesis funding output.
2 Treasury Wars

Players spend from capped treasuries. The accepted TN12 path now proves two cumulative spends, continuation state, and relocked change.

  • Active RecurringTreasuryVault.sil rail.
  • Accepted covenant-genesis funding output.
  • Two accepted under-cap covenant spends.
  • Over-cap continuation candidate blocked locally.
3 Covenant-Owned Asset Duel

An asset move requires the owner covenant input in the same transaction. The proof uses sibling authority instead of nested execution.

  • ICC / sibling-input authorization.
  • Accepted TN12 genesis funding output.
  • Missing or wrong sibling fails.
