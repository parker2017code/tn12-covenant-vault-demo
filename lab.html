Self-serve runbook

Run it yourself.

Start with tKAS, pick a lane, use your wallet, then replay the accepted evidence before trusting the UI.

Before copying commands

Run npm ci first, then check docs/COMMAND_RUNBOOK.md. Some commands only rebuild artifacts; wallet and submit commands may write testnet-only files under .local/ or broadcast to TN12.

1 Get TN12 tKAS

Open the faucet, fund a fresh kaspatest: address, then paste the txid/outpoint into Manual funding.

Open funding importer
2 Pick a lane

Use Live Play for accepted transfers, Invoices for payload receipts, Assurance/Escrow for covenant spend rules, and DeFi Lab for reducers and spend checks.

Open Live Play
3 Use your own wallet

Export a wallet-standard request, review exact fields, sign outside the repo, return signed bytes, then run validation.

Open wallet handoff
4 Replay before believing it

Promote app state only after accepted txid, payload/output match, duplicate guard, and replay checks pass.
