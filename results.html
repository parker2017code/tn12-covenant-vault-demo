Safe playground design

How people should play with this.

The public playground should use throwaway TN12 wallets and faucet-funded roles. People can run real testnet actions without depending on shared repo keys.

1. Generate roles

Create fresh local testnet wallets for operator, pool, user A, user B, executor, and reviewer. Store secrets in browser/session or .local/, never in committed artifacts.

2. Fund with faucet

Show each kaspatest: address with copy buttons and required tKAS amounts. Users paste those into the TN12 faucet or send from their own funded wallet.

3. Run guided flows

Submit payload receipts, local-key transfers, deposits, payouts, scheduler bids, and proof bindings. Every result gets an explorer txid and an artifact row.

Future implementation target: playground.html plus a playground:* script group for wallet creation, faucet checklist, scenario submit, receipt verification, and cleanup.
